# 🌄 Photo Wallpaper

Android-приложение: **обои рабочего стола из «фото дня» Bing**.
Без регистраций, без API-ключей, без Google Cloud — установил и пользуешься.

## ✨ Возможности

| | |
|---|---|
| 📅 Галерея | Последние 8 «фото дня» Bing в высоком качестве |
| 🔄 Автосмена | **Раз в час** (по кругу через 8 фото) или **раз в сутки** (фото дня) |
| 🚀 Старт ротации | С какого из 8 фото начать в часовом режиме |
| 📷 Тап по фото | Сразу ставит выбранное фото обоями |
| 📴 Офлайн-кэш | Если Bing недоступен — используется последний сохранённый список |
| ⚙️ Фон | Всё работает через WorkManager, без открытых окон приложения |

## 🔧 Как это работает

Приложение обращается к **публичному эндпоинту Bing** (тот же, что у
официального приложения Bing Wallpaper для Windows):

```
https://www.bing.com/HPImageArchive.aspx?format=js&idx=0&n=8
```

Он возвращает JSON с последними 8 фото дня: дата, подпись/автор и базовый URL
изображения. Само фото скачивается в нужном разрешении:

| Суффикс | Разрешение | Использование |
|---------|-----------|---------------|
| `_UHD.jpg` | 3840×2160 | обои на телефон |
| `_1920x1080.jpg` | 1920×1080 | (запас) |
| `_1366x768.jpg` | 1366×768 | превью в галерее |

Ключи, токены и учётные записи **не нужны** — поэтому ошибка 400 из
Google OAuth здесь принципиально невозможна 🙂

## 📦 Структура

```
app/src/main/java/com/photowallpaper/
├── MainActivity.kt       — экран: галерея + настройки
├── BingApi.kt            — загрузка списка фото Bing + скачивание
├── WallpaperApplier.kt   — скачивание UHD и установка обоев
├── WallpaperWorker.kt    — WorkManager: фоновая периодическая смена
└── SettingsManager.kt    — SharedPreferences (интервал, старт, кэш)
```

## 📲 Установка

1. Скачайте `app-debug.apk`:
   - GitHub → **Actions** → последняя ✓ сборка → **Artifacts** → `PhotoWallpaper-debug`
   - либо создайте тег: `git tag v1.2 && git push origin v1.2` → **Releases**
2. Установите на телефон (разрешите «установку из неизвестных источников»)
3. Откройте приложение → включите «Автоматическую смену» → готово

> Минимальная версия Android: **8.0 (API 26)**. targetSdk 35 (Android 15) —
> полностью совместимо с новыми версиями Android.

## 🔄 Сборка

GitHub Actions собирает APK **автоматически при каждом push**
(`.github/workflows/build.yml`), при теге `v*` создаётся GitHub Release
(`.github/workflows/release.yml`).

Локальная сборка (нужен Android SDK + JDK 17):

```
./gradlew assembleDebug
```
